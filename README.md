## About the Project

**TanIA** is an innovative decision support system designed to enhance patient experience and optimize hospital workflows using Natural Language Processing (NLP). The system bridges communication between patients and healthcare providers, ensuring efficient and accurate interactions.

### Key Features

- **Patient Interaction:** Welcomes patients and collects complaints through text or speech inputs.
- **Doctor Recommendation:** Directs patients to the most suitable medical specialist based on their symptoms.
- **Preliminary Diagnosis Reporting:** Analyzes symptoms and provides doctors with possible preliminary diagnoses and conditions.

This project aims to make healthcare services more accessible, precise, and efficient.
